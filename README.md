# AeroPlay

A Frutiger Aero-inspired web music player that channels peak 2000s tech nostalgia—complete with glossy glassmorphism, floating Aqua bubbles, and customizable skeuomorphic themes.

## ✨ Core Features

* **Frutiger Aero UI:** A deeply immersive, nostalgic skin built with glossy, glassmorphic web components, custom 3D widgets, and fluid HTML5 canvas animations.
* **Personalized Customization & Settings:** 
  * **Dynamic Backgrounds:** Custom wallpaper loader and gradient selector.
  * **Day/Night Modes:** Seamless toggling between light and dark Aero themes.
  * **Accent Color Engine:** Customizable glass tinting and theme colors.
* **Audio Feature Extraction:** Real-time processing of uploaded audio tracks (`.mp3`, `.wav`, `.ogg`) to extract raw acoustic properties via the Web Audio API.
* **Algorithmic AI Mood Detection:** Python-powered backend that scans rhythm, tempo, and sonic energy to dynamically tag and classify track moods.

---

## Tech Stack

* **Frontend:** React.js, Web Audio API, HTML5 Canvas (Deployed on Netlify)
* **Backend:** Python, FastAPI, Librosa, Scikit-Learn (Deployed on Render)
